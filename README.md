# FUTURE_PE_01

### Business Chosen

Aura Beauty Studio

### Business Type

Salon

### Location

Hyderabad

### Objective

To create a reusable AI prompt system that generates high-quality, conversion-focused website copy for local businesses.

### Tools Used

* ChatGPT
* GitHub

### Deliverables

* Homepage Copy
* Services Page Content
* CTA Sections
* Structured Prompt Framework

### Prompt Logic

The prompt accepts business details such as name, type, location, target customers, and tone, then generates website-ready content tailored to that business.

### Outcome

A reusable prompt engineering framework capable of generating professional website copy for salons and other local businesses.
## Website Prototype

A website prototype for Aura Beauty Studio was created using Lovable AI based on the generated website copy and prompt framework.

### Features Implemented

* Homepage with value proposition
* Services section
* Appointment booking form
* Contact section
* Mobile-responsive layout
